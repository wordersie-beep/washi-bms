## Как подключить в cTrader

Иконка **не задаётся из кода**: SDK `cTrader.Automate` 1.0.21 не принимает её
ни атрибутом, ни свойством проекта — в задачах сборки нет ни одного параметра
для неё, а в формате `.algo` есть только флаг `IconIncluded`, который
выставляет сама платформа.

Порядок такой:

1. cTrader → **Algo** → **сиБоты** → QuantCryptoV3
2. Кнопка с шестерёнкой на карточке бота → **Edit details** / **Изменить**
3. Загрузить `icon-512.png`, вставить описание ниже
4. Сохранить

Описание, заданное в `.csproj` (`<Description>`), попадает в метаданные сборки
и видно в свойствах файла, но карточку в интерфейсе не меняет.

## Что означает иконка

Щит — приоритет номер один: **сохранение капитала**. Он снаружи и охватывает
всё остальное, потому что каждое решение внутри проходит через него.

Ступенчатая линия — **распределение исходов**, а не график цены. Оранжевым
отмечен левый хвост: система принимает решения по НИЖНЕЙ границе ожидания,
и управляет она именно хвостом, а не надеждой.

Чего на иконке нет намеренно: золота, символов валют, стрелок вверх. Обещание
прибыли в оформлении было бы первым нарушением правила «ничего не обещать».

## Описание для карточки

### Короткое (одна строка)

```
Адаптивная мультистратегийная система для крипто-CFD. Приоритет — сохранение капитала.
```

### Полное

```
QuantCryptoV3 — адаптивная квантовая мультистратегийная система для торговли
крипто-CFD на малых таймфреймах, работающая круглосуточно.

ЧТО ВНУТРИ

Девять стратегий голосуют ансамблем: следование тренду, импульс, пробой,
откат, возврат к средней, расширение волатильности, структура рынка,
разворот и базовая линия. Голоса взвешены по качеству и уменьшены за
пересечение — две стратегии, смотрящие на одно и то же, не считаются за две.

Вероятность успеха оценивается байесовской иерархической моделью с усадкой
и проверяется на калибровку: система измеряет, насколько её «70%» на самом
деле означают 70%, и исправляет смещение по эмпирическим данным.

Решение принимается по НИЖНЕЙ границе ожидания, а не по точечной оценке.
Цель ограничена историческим MFE: цель, до которой цена не доходила, — это
не цель, а допущение.

КАК УСТРОЕН РИСК

Приоритет жёстко задан: выживание капитала, затем положительное ожидание,
затем стабильность, и только потом прибыльность.

Размер позиции определяют девять множителей, и каждый из них не превышает
единицы: усиление после убытка невозможно по построению. Мартингейл,
сеточное усреднение и удвоение на убытке отсутствуют в коде как класс.

Лимиты: риск на сделку, суммарный риск портфеля, дневной и недельный убыток,
просадка по четырём горизонтам, серия убытков, корреляционные кластеры,
направленная экспозиция, маржа и риск разорения. Состояние переживает
перезапуск: счётчик серии и дневная точка отсчёта не обнуляются сбоем.

АДАПТАЦИЯ

Стратегия, чьё ожидание деградировало, понижается в весе, затем
отключается — и продолжает наблюдаться виртуально, с настоящим планом
выхода и настоящими издержками. Вернуться в работу она может только доказав
положительное ожидание на этой теневой записи.

ЧЕСТНОСТЬ ПО УСТРОЙСТВУ

NO TRADE — полноценное и часто правильное решение. На настройках по умолчанию
система отклоняет подавляющее большинство сигналов, и каждый отказ записан с
причиной. Признак жизни печатается по таймеру, чтобы правильно молчащая
система не выглядела мёртвой.

Четыре режима: Shadow и Paper не отправляют приказы брокеру вообще, Demo
работает на демо-счёте, Live требует отдельного явного подтверждения.

ТРЕБОВАНИЯ

cTrader 4.x с cTrader Algo. Совместим с cTrader Cloud: без графики, файловой
системы и сети, одна сборка, AccessRights.None. Нужен крипто-символ с
круглосуточными часами торговли — бот сам проверяет это при старте и
сообщает, если инструмент торгуется с перерывами.

ПРЕДУПРЕЖДЕНИЕ

Торговля с плечом связана с риском потери всего капитала. Система не снижает
рыночный риск — она управляет размером позиции и ограничивает убытки в
рамках заданных лимитов. Стоп-лосс не гарантирует цену исполнения: при гэпе
убыток может превысить запланированный, и это неустранимо размером позиции.

Прибыльность не гарантируется и не обещается.
```
