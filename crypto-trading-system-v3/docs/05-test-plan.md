
## Что тесты уже нашли

Список приводится не для отчётности, а потому что он показывает, какого рода ошибки
здесь ловятся. Каждая из этих ошибок прошла бы ревью.

| Дефект | Последствие, если бы не нашли |
|---|---|
| ATR ранжировался в единицах цены | В растущем инструменте перцентиль волатильности навсегда 1.0 → все риск-контроли постоянно на максимуме |

| Восстанавливающаяся стратегия взвешивалась по записи, которая её отключила | Вес 0 → нет сделок → нет новой записи → восстановление недостижимо |

| Перцентиль при одинаковых значениях = 1.0 | При фиксированном спреде брокера система отклоняла **100%** сигналов |
| Лимит проскальзывания в пипсах | 8 пипсов = 8 центов на BTC → все ордера отклонялись |

## Уровни тестирования

### 1. Численность и индикаторы

Проверяется арифметика, на которой стоит всё остальное.

* **Кольцевые буферы**: индексация от новейшего, вытеснение, 1000 оборотов,
  границы.
* **Скользящие окна**: среднее и дисперсия против прямого вычисления после
  вытеснения; дисперсия постоянного ряда строго ≥ 0 (накопление округлений может
  увести её в минус); mid-ranks при одинаковых значениях.
* **ATR сверяется с независимой наивной реализацией Уайлдера**, написанной в самом
  тесте. Это не тавтология: две реализации одного определения, сделанные по-разному.
* **Масштабная инвариантность**: один и тот же ценовой путь на уровне 60 000 и на
  уровне 0.5 обязан давать одинаковые нормированные признаки. Без этого ничто,
  выученное на BTC, никуда не переносится.
* **Свинги подтверждаются не раньше срока**: тест явно проверяет, что пивот не
  объявлен до закрытия подтверждающих баров.
* **ГСЧ**: детерминизм по сиду, единичная дисперсия гауссианы, независимость
  последовательных выборок (проверялось при расследовании ложной корреляции).

### 2. Данные, признаки, режим

* Отклонение дубликатов, баров из прошлого, некорректных баров — **без частичного
  применения**.
* Обнаружение разрывов в данных.
* Качество данных: устаревшая котировка, инвертированный спред, недостаток истории,
  запрет торговли по инструменту.
* Все 60+ признаков конечны на нормальном рынке (проверяется поимённо).
* Режим: тренд вверх, тренд вниз, боковик классифицируются верно; один контрарный
  бар не переключает режим; при переходе риск подавляется; сильный тренд не
  называется «просто волатильностью».

### 3. Стратегии и ансамбль

* **Специализация**: mean reversion обязана иметь нулевую пригодность во всех
  трендовых и беспорядочных режимах. Проверяется явно.
* **Барьер исключений**: стратегия, бросающая исключение, воздерживается, а не
  роняет остальные восемь.
* **Направление**: обход всего ценового пути, а не одного бара; каждый сигнал
  сверяется с измеренной самой стратегией силой тренда.
* **Корреляция сигналов**: структурное пересечение обнаруживается с первого бара;
  эмпирическое дублирование повышает оценку; устойчивое *несогласие* не считается
  дублированием.
* **Вес**: потолок 40% соблюдается при любых входах; сумма весов = 1; пять сделок не
  сдвигают вес заметно.
* **Жизненный цикл**: деградация → отключение → теневой период → восстановление,
  включая проверку, что восстановление даёт **ненулевой** вес.

### 4. Вероятность и матожидание

* Без истории оценка сидит на безубыточном винрейте для запрошенного RR — не на
  лестном допущении.
* Малая выборка почти не двигает оценку; большая — доминирует над априором.
* Срезы по режимам разделяются; глобальная запись не «топит» специфический срез.
* **Вложенные срезы не считаются по разу на уровень** (регрессионный тест на
  найденный дефект).
* Калибровка: хорошо калиброванная модель получает высокую оценку; переуверенная
  обнаруживается и её прогнозы сжимаются; тонкие корзины исключаются.
* EV: одно и то же точечное значение с широкими интервалами **не торгуется**;
  издержки сами по себе превращают выигрышную установку в отказ; цель ограничивается
  историческим MFE.

### 5. Риск, портфель, сайзинг, выходы

* **Анти-мартингейл**: 20 убытков подряд, после каждого — утверждение, что множитель
  не вырос.
* **Жёсткий потолок**: 3000 случайных комбинаций девяти множителей, ни одна не
  превышает потолок.
* Лестница постур в правильном порядке; смягчение по одной ступени; гистерезис.
* Корреляция: идентичные ряды → 1.0, зеркальные → −1.0, независимые → мало;
  кластеризация транзитивна; нумерация кластеров детерминирована.
* Выходы: безубыток **выше** входа для лонга; стоп двигается только в сторону
  снижения риска; частичное закрытие оставляет раннер; стоп по времени не срабатывает
  на работающей сделке; MAE-распределение расширяет слишком узкий стоп.

### 6. Сквозные и восстановление

* Полный прогон по тренду, боковику и падению с ростом волатильности: без
  исключений, состояние согласовано с брокером, лимит позиций соблюдён.
* Совокупный риск никогда не превышает бюджет.
* Каждая сделка записана с полным контекстом решения.
* Идемпотентность: один бар → один идентификатор; отклонённый ордер **не блокирует**
  сигнал навсегда; защита переживает рестарт и остаётся ограниченной по памяти.
* Восстановление: позиции у брокера без контекста → остановка, а не догадки;
  повреждённое состояние отбрасывается целиком; сбой записи состояния не останавливает
  торговлю.
* Ценность фильтров: отслеживаются только суждения о рынке; бар, задевший оба уровня,
  разрешается против фильтра; недостаточная выборка не даёт объявить фильтр вредным.

## Чего тесты НЕ доказывают

Это важнее списка того, что они проверяют.

**Тесты не доказывают прибыльность.** Ни один из них не утверждает, что система
зарабатывает. Сквозные тесты используют синтетический рынок с искусственно завышенным
априорным винрейтом (80%) — это способ гарантированно провести кандидата через
экономические проверки, а не оценка чего бы то ни было. Статистика такого прогона
(PF 4.18, винрейт 76%) — артефакт настроек теста и не имеет отношения к ожидаемым
результатам.

**Тесты не доказывают наличие преимущества.** Преимущество может быть установлено
только на реальных исторических данных, вне выборки, с реальными издержками, и
подтверждено планами из документов 06–11.

Что тесты действительно доказывают: арифметика верна, инварианты соблюдаются, слои
соединены правильно, и система ведёт себя предсказуемо при сбоях.
