## Стратегии

```
        ┌─────────────────────────────┐
        │  IStrategy                  │
        │  ─────────                  │
        │  Name                       │
        │  Kind                       │
        │  RegimeFit: Regime → 0..1   │  ← где стратегия заявляет компетентность
        │  Families: FeatureFamily[]  │  ← для структурного выявления дублирования
        │  Evaluate(ctx) → Signal     │
        └──────────────┬──────────────┘
                       │
        ┌──────────────▼──────────────┐
        │  StrategyBase (abstract)    │
        │  ─────────────────────────  │
        │  • барьер исключений        │  одна сломанная стратегия
        │  • гейт по regime fit       │  не роняет остальные восемь
        │  • Combine() — ГЕОМЕТРИЧЕСКОЕ среднее:
        │    близкий к нулю член тянет весь балл вниз,
        │    как и должно вести себя необходимое условие
        └──────────────┬──────────────┘
                       │
   ┌────────┬──────────┼──────────┬─────────┬─────────┬────────┬────────┐
   ▼        ▼          ▼          ▼         ▼         ▼        ▼        ▼
Trend   Momentum   Breakout   Pullback  MeanRev   VolExp  Structure Reversal
Follow                                                                    +Baseline
```

Каждая стратегия объявляет `RegimeFit`. `StrategyRegistry.Validate()` при старте
проверяет два условия и падает, если они нарушены:

1. каждый торгуемый режим покрыт хотя бы одной стратегией;
2. **ни одна стратегия не заявляет ненулевую пригодность во всех режимах** —
   такая стратегия не специализирована, а значит, у неё нет тезиса.

## Ключевые инварианты, закреплённые типами

| Инвариант | Как обеспечен |
|---|---|
| Индикаторы не видят формирующийся бар | `OnBarClosed(in Candle)` — единственный вход |
| Сайзинг не может увеличить риск | все множители ≤ 1.0 по построению |
| Стоп двигается только в сторону снижения риска | `PositionManager.IsImprovement` |
| Один сигнал → один ордер | `IdempotencyGuard`, отметка ДО отправки |
| Виртуальные сделки не портят статистику | `PerformanceStore.Record` ветвится по `IsVirtual` |
| Провал слоя = отказ, а не исключение | барьеры в `StrategyBase`, моделях, сериализации |
