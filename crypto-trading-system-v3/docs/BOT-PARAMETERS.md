# Параметры бота

Файл собирается автоматически из `QuantCryptoV3Bot.cs` скриптом
`scripts/generate-parameter-reference.py`. Править его руками бессмысленно:
предполётная проверка сверяет его с кодом и падает при расхождении.

Те же описания видны в cTrader как подсказки к параметрам.

## Режим

| Параметр | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| Режим работы | `OperatingMode.Shadow` | — | Shadow и Paper НЕ отправляют приказы брокеру — счёт не затрагивается. Demo и Live отправляют. Порядок освоения: Shadow, Paper, Demo, Live. |
| Подтверждаю реальную торговлю | `false` | — | Обязательно для режима Live на реальном счёте. Без этого система откажется запускаться: одного параметра «Режим» недостаточно, чтобы начать двигать настоящие деньги. |
| Доп. символы (через запятую) | `—` | — | Инструменты помимо графика, например ETHUSD,SOLUSD. Эталонный добавляется сам. Каждый инструмент — это 6 рядов данных; разумный потолок для облака 4–6 инструментов. |
| Сигнальный таймфрейм | `Tf.M5` | — | Таймфрейм, на закрытии которого принимаются решения. Таймфрейм ГРАФИКА на работу бота не влияет вообще. |
| Контекстный таймфрейм | `Tf.H1` | — | Даёт тренд более высокого порядка. Должен быть медленнее сигнального, иначе проверка тренда перестаёт что-либо проверять. |
| Эталонный символ | `BTCUSD` | — | Инструмент, задающий общий контекст рынка. Смещает вероятность, но никогда не накладывает вето. Подписывается даже если им не торгуют. |
| Дашборд каждые N минут | `60` | 5 … 1440 | Полный отчёт: капитал, просадки, портфель, режимы, стратегии, калибровка, причины отказа. |
| Признак жизни каждые N минут | `15` | 1 … 240 | Одна строка о состоянии бота. Главный ответ на вопрос «он работает или завис»: правильно молчащая система неотличима от мёртвой. |
| Подробный журнал отказов | `false` | — | Да — в лог идёт каждое отклонённое решение. Нет — только смена причины. Включайте для разбора, на рабочем режиме выключайте. |

## Риск

| Параметр | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| Риск на сделку, % | `0.35` | 0.01 … 2.0 | Доля капитала, теряемая при срабатывании стопа. Это ПОТОЛОК: все адаптивные множители только уменьшают его, никогда не увеличивают. |
| Жёсткий предел риска, % | `1.0` | 0.1 … 3.0 | Абсолютный потолок риска на сделку. Не может быть превышен ничем и никогда. |
| Общий риск портфеля, % | `2.0` | 0.2 … 6.0 | Суммарный риск всех открытых позиций. Должен превышать риск на сделку, иначе ни одна сделка не пройдёт. |
| Дневной лимит убытка, % | `2.0` | 0.5 … 10.0 | Достигнут — торговля останавливается до следующего дня. Точка отсчёта переживает перезапуск бота. |
| Недельный лимит убытка, % | `5.0` | 1.0 … 20.0 | Должен быть больше дневного. Достигнут — остановка до следующей недели. |
| Макс. просадка 24ч, % | `4.0` | 1.0 … 20.0 | Просадка от пика капитала за сутки. Превышена — новые позиции запрещены. |
| Макс. просадка всего, % | `18.0` | 5.0 … 50.0 | Просадка от исторического пика капитала. Самый последний рубеж обороны. |
| Макс. одновременных позиций | `4` | 1 … 10 | Потолок числа открытых позиций. Работает вместе с лимитами по символу, кластеру и направлению. |

## Сигнал

| Параметр | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| Мин. уверенность режима | `0.55` | 0.3 … 0.95 | Ниже этого порога режим рынка считается неопределённым, и сделки не открываются. NO TRADE — полноценное решение. |
| Мин. уверенность ансамбля | `0.55` | 0.3 … 0.95 | Порог согласия стратегий. Голоса взвешены по качеству и уменьшены за пересечение: две стратегии, смотрящие на одно и то же, не считаются за две. |
| Макс. вес одной стратегии | `0.40` | 0.15 … 0.60 | Потолок влияния любой стратегии на решение. Не даёт ансамблю выродиться в одну стратегию после удачной полосы. |

## Преимущество

| Параметр | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| Базовое мин. преимущество, R | `0.10` | 0.0 … 0.5 | Минимальное ожидание сверх издержек, без которого сделка не открывается. Ноль означает торговлю при нулевом ожидании. |
| Сигм для нижней границы EV | `1.0` | 0.0 … 3.0 | Решение принимается по НИЖНЕЙ границе ожидания, а не по точечной оценке. Больше сигм — строже требование к статистической уверенности. |
| Мин. соотношение риск/прибыль | `1.3` | 0.8 … 4.0 | Отношение цели к стопу. Цель дополнительно ограничивается историческим MFE: цель, до которой цена не доходила, — не цель, а допущение. |
| Сила байесовского априора | `25.0` | 5.0 … 100.0 | Сколько наблюдений «весит» априорная оценка. Больше — медленнее реакция на новые данные, но меньше шанс принять случайную серию за преимущество. |

## Выходы

| Параметр | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| Стоп, ATR | `1.6` | 0.5 … 5.0 | Базовая ширина стопа в единицах ATR. Фактическая выбирается из структуры рынка и распределения MAE, этот параметр задаёт запасной вариант и потолок. |
| Цель 1, R | `1.2` | 0.5 … 5.0 | Первая цель в единицах риска. По ней закрывается часть позиции. |
| Цель 2, R | `2.2` | 0.8 … 10.0 | Вторая цель. Остаток после неё ведётся трейлингом. |
| Безубыток при, R | `0.9` | 0.2 … 3.0 | Прибыль, при которой стоп переносится в безубыток — с учётом издержек, а не в точку входа. |
| Трейлинг тренда, ATR | `2.2` | 0.8 … 6.0 | Дистанция трейлинг-стопа в ATR. Меньше — раньше выбьет из тренда, больше — отдаст больше прибыли на откате. |

## Исполнение

| Параметр | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| Макс. проскальзывание, ATR | `0.25` | 0.05 … 2.0 | Потолок проскальзывания в долях ATR. Берётся БОЛЬШЕЕ из этого и лимита в спредах. |
| Макс. проскальзывание, спредов | `3.0` | 1.0 … 20.0 | Потолок проскальзывания в текущих спредах. Работает там, где ATR ещё не набран. |
| Сверка каждые N минут | `5` | 1 … 60 | Частота сверки позиций с брокером. Расхождение — состояние, в котором любое решение принимается вслепую, поэтому оно вызывает остановку. |

Всего параметров: 32.
