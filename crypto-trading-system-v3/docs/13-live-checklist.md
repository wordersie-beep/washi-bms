# Чеклист перед реальной торговлей

## Прежде всего

Этот документ не про то, как получить разрешение выйти в бой. Он про то, как честно
ответить себе на вопрос, есть ли основания. В большинстве случаев честный ответ —
«нет», и это нормальный результат работы, а не неудача.

**Система не обещает прибыли.** Ни один из прогонов, описанных в документах 06–11, не
может этого доказать. Они могут только не опровергнуть наличие преимущества.

## Ворота: всё или ничего

Каждый блок — ворота. Провал любого пункта означает возврат назад, а не переход с
оговоркой.

## Запуск в бою

Только при прохождении **всех девяти ворот**.

```
Режим работы                  = Live
Подтверждаю реальную торговлю = true
RiskPerTradePercent           = 25–50% от протестированного
MaxTotalOpenRiskPercent       = 50% от протестированного
Доп. символы                  = (пусто; добавлять по одному позже)
```

Сниженный риск — не перестраховка. Демо-исполнение отличается от реального: другая
очередь, другая ликвидность, другой приоритет. Первые недели боя — продолжение
проверки.

### Первая неделя

```
Ежедневно:
☐ Дашборд прочитан целиком
☐ Каждая сделка проверена вручную: вход, стоп, размер — соответствуют журналу
☐ Проскальзывание сравнено с моделью
☐ Нет исключений
```

### Масштабирование

Увеличивать риск **только** при одновременном выполнении:

```
☐ ≥ 50 реальных сделок
☐ Матожидание в бою в пределах ожидаемого по валидации
☐ ECE калибровки < 10%
☐ Качество исполнения ≥ 0.8
☐ Просадка в пределах P95 Монте-Карло
☐ Прошёл минимум месяц
```

Шаг увеличения — **не более +25% за раз**, с повторной проверкой тех же условий.

```
Рост капитала САМ ПО СЕБЕ не является основанием для увеличения риска.
```

Это раздел 109 спецификации. Основание — накопленная статистика, а не результат.

## Немедленная остановка

Остановить торговлю и разбираться, если:

```
☐ Просадка превысила P95 Монте-Карло
☐ ECE калибровки > 15%
☐ Множитель проскальзывания > 3.0
☐ Расхождение при сверке
☐ Необработанное исключение в логе
☐ Матожидание в бою существенно хуже валидированного при выборке ≥ 30 сделок
☐ Поведение системы непонятно
```

Последний пункт — полноценное основание. Система, поведение которой вы не понимаете,
управляет вашими деньгами без вашего участия.

## Чего эта система НЕ делает

Прямо, чтобы не осталось иллюзий:

* **Не гарантирует прибыль.** Ничего не гарантирует.
* **Не исключает убыточные периоды.** Они будут, и длинные.
* **Не исключает просадки.** Ожидаемая просадка — P95 из Монте-Карло, и она наступит.
* **Не заменяет понимания.** Все защиты можно обойти неверной настройкой.
* **Не делает плохую стратегию хорошей.** Она делает отсутствие преимущества видимым —
  это её главная польза и, возможно, единственный результат, который вы получите.

Самый вероятный и совершенно нормальный исход всей этой процедуры — вывод, что
устойчивого преимущества на доступных данных нет. Система спроектирована так, чтобы
этот вывод был получен на бэктесте и в теневом режиме, а не на реальном счёте.
