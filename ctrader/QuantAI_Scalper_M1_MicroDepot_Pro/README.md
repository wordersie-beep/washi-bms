# QuantAI_Scalper_M1_MicroDepot_Pro — cBot для cTrader (v2.0.0)

Скальпер на нескольких рынках сразу: **форекс на M1 в будни и криптовалюты на M5 круглосуточно, включая
выходные**. Один экземпляр бота торгует все символы из двух списков — до 8 открытых позиций, по одной на символ.
Бот ловит микро-импульсы по тиковому ускорению. Входит на пробое сквиза у 20 EMA (Боб Вольман) или после
ложного прокола 10-барного экстремума. Каждый сигнал проверяет наивный байесовский классификатор (своя модель
на каждый символ). Позицию бот ведёт так: TP1 60 %, микро-безубыток, ATR-трейлинг остатка, выход по времени.

Готовый файл: [`release/QuantAI_Scalper_M1_MicroDepot_Pro.algo`](release/QuantAI_Scalper_M1_MicroDepot_Pro.algo) — ставится с телефона,
все настройки уже выставлены. Исходник — один файл
[`QuantAI_Scalper_M1_MicroDepot_Pro/QuantAI_Scalper_M1_MicroDepot_Pro.cs`](QuantAI_Scalper_M1_MicroDepot_Pro/QuantAI_Scalper_M1_MicroDepot_Pro.cs).
Без внешних библиотек, `AccessRights.None` — запускается в облаке cTrader.

## Что торгует из коробки

| | Форекс | Крипта |
| --- | --- | --- |
| Символы | EURUSD, GBPUSD, USDJPY, AUDUSD, USDCAD, USDCHF | BTCUSD, ETHUSD |
| Таймфрейм сетапов, ATR и выхода по времени | M1 (выход через 5 минут) | M5 (выход через 25 минут) |
| Когда | 06:00–20:00 UTC, пн–пт | 24/7, в том числе суббота и воскресенье |
| Лимит спреда | ≤ 12 % ATR | ≤ 35 % ATR |

- **Объём:** 4 лота на сделку (`Fixed Lots Per Trade`). Бот уменьшает объём, если 4 лота не проходят по марже:
  - одна сделка занимает не больше **30 % свободной маржи**;
  - все позиции вместе — не больше **90 % средств** (уровень маржи не ниже ~111 %).
- **До 8 позиций одновременно**, не больше одной на символ.
- Дневной лимит убытка 6 % на весь счёт. Пауза после 4 убытков подряд и кулдаун 30 с — отдельно по каждому символу.
- Символ, которого нет у брокера, пропускается со строкой `MARKET ...: not offered on this account`.
  Написание вроде `BTC/USD` или `BTCUSD.` бот находит сам.

Как это выглядит на счёте 49 000 EUR с плечом 1:30 (1:2 на крипту), если все 8 сигналов пришли одновременно
(курсы валют условные, расчёт — тот же код, что в боте):

| Сделка | Объём | Занято маржи |
| --- | --- | --- |
| 1. EURUSD | 4.00 лота | 27 % |
| 2. GBPUSD | 2.79 лота | 49 % |
| 3. USDJPY | 2.63 лота | 64 % |
| 4. AUDUSD | 2.79 лота | 75 % |
| 5–8 | всё меньше | до 90 %, дальше отказ `Total margin limit reached` |

На практике позиции живут минуты, и одновременно их обычно меньше. В выходные форекс закрыт,
и крипта получает весь счёт: 30 % от 49 000 EUR при плече 1:2 — позиция примерно на 29 000 EUR
(около 0.3 BTC при цене 110 000 $). На счёте 50 EUR те же настройки дают одну позицию 0.01 лота на форексе.
BTC на 50 EUR, скорее всего, не откроется: даже минимальный объём требует больше маржи, в журнале будет
`Insufficient margin`.

## Установка с телефона (ничего настраивать не нужно)

1. Открыть файл `QuantAI_Scalper_M1_MicroDepot_Pro.algo` в **cTrader Mobile** («Поделиться» → cTrader,
   или сохранить в «Файлы» и открыть оттуда). Бот появится во вкладке **cBots**.
2. **Если стоит старая версия:** остановить её экземпляр и **удалить** его, затем добавить новый.
   Старый экземпляр хранит свои старые значения параметров. Новый получит все значения v2.0.0.
   На демо-счёте в облаке работает только 1 экземпляр — он и торгует все 8 рынков.
3. Нажать **+** рядом с именем бота — экземпляр создаётся на **EURUSD M1**, график значения не имеет:
   символы берутся из списков в параметрах.
4. **Start** — бот работает в облаке cTrader 24/7, телефон можно выключить.

При запуске бот загружает историю и обучает AI по каждому символу, это может занять до минуты. Первые
5 минут (крипта) и 1 минуту (форекс) новых сделок нет — прогревается тиковый движок. Затем по каждому
символу AI один раз переобучается на реальном спреде после 300 тиков (`AI RETRAIN` в журнале).

На компьютере: двойной клик по `.algo` (cTrader Windows/Mac) либо Algo → cBots → New → вставить код
из `.cs` → Build (Ctrl+B).

Требуется **cTrader 5.0+** (Algo API 1.0.9+: Windows, Mac, Web, Mobile, облако). Сборка проверена против
cTrader.Automate 1.0.9, 1.0.14 и 1.0.21 — 0 ошибок, 0 предупреждений; синтаксис C# 7.3.

Бэктест — только с данными **Tick data from server (accurate)**. На «m1 bars» тиковый движок видит
лишь синтетические тики, и результат ничего не говорит о реальной работе.

## Почему бот не торгует — как узнать за минуту

Каждые 15 минут в журнале экземпляра (cTrader → cBots → экземпляр → Log) появляется сводка: общая строка
и по строке на каждый открытый рынок:

```
STATUS 10:15 UTC since 10:00 | positions 2/8 | today 5 trade(s), +84.20 EUR
EURUSD | squeeze armed on 6 bar(s), sweeps 1 | signals 4, trades 1 | AI conf 46%-57% (avg 51%, target 50%) | skipped by: Tick velocity 2, Spread 1 | now spread 0.1p <= limit 0.2p (12% of ATR 1.7p), tick burst 1.30x (need 2.00x), AI ready, in session | today 2 trade(s)
BTCUSD | no setup formed | signals 0, trades 0 | now spread 18.00 <= limit 63.00 (35% of ATR 180.00), ...
```

В выходные строки форекса пропадают (`market closed: EURUSD,...`), остаются BTCUSD и ETHUSD.

- `no setup formed` — рынок не дал ни сквиза, ни свипа.
- `skipped by: Spread …` — спред больше лимита. Если так на форексе весь день — счёт со спредом-наценкой
  (у Pepperstone это Standard), нужен Razor. Для крипты лимит поднимается параметром `Crypto Max Spread / ATR`.
- `skipped by: Tick velocity …` — пробой без всплеска тиков (≥ N × среднего).
- `skipped by: AI confidence …` — классификатор не уверен (ниже `Min Confidence`).
- `skipped by: Max open positions / Size/margin` — уже 8 позиций или маржа занята.
- `OUT OF SESSION` — форекс вне 06:00–20:00 UTC; крипту это не касается.

## Pepperstone (cTrader)

- **Форекс — счёт Razor**: сырой спред EURUSD в среднем около 0.09 пипса, комиссия $3 за лот за сторону. Под него
  рассчитан фильтр `Forex Max Spread / ATR = 0.12`. На **Standard** (наценка 1 пипс) фильтр почти никогда не пропустит
  вход; бот об этом прямо напишет (`WARNING`).
- **Крипта**: торгуется 24/7, спред BTCUSD от $15, ETHUSD от $2, без комиссии, плечо для розничных клиентов в ЕС — 1:2.
  Поэтому крипта идёт на M5: на M1 её спред съедает слишком большую часть движения.
- У британских розничных счетов (FCA) крипто-CFD могут быть недоступны — бот тогда напишет
  `not offered` и будет торговать только форекс.
- 4 лота EURUSD на Razor — это около $24 комиссии за круг. TP1 на M1 — 1–2 пипса, поэтому комиссия
  забирает заметную часть прибыли каждой сделки.

## Как принимается решение (по каждому символу отдельно)

1. **Сетап** — на закрытии бара сигнального таймфрейма (форекс M1, крипта M5):
   - **SQZ (20 EMA Squeeze).** Последние `Squeeze Bars` баров помещаются в коробку не выше
     `Squeeze Max Range` × ATR, EMA20 внутри коробки или не дальше `Squeeze Max EMA Gap` × ATR.
     Вход — на том тике, который пробивает коробку ± `Breakout Buffer Pips`.
   - **SWP (Liquidity Sweep).** Бар проколол High/Low предыдущих `Sweep Lookback Bars` (10) баров
     минимум на `Sweep Min Pierce Pips` и закрылся обратно. Вход — когда цена возвращается за EMA20
     (± буфер) в течение `Sweep Max Bars To EMA Reclaim` баров. Новый экстремум за хвостом отменяет сетап.
2. **Фильтры на тике триггера.** Все не пройденные фильтры пишутся в журнал одной строкой `SKIP`:
   - спред / ATR ≤ лимита рынка (форекс 0.12, крипта 0.35);
   - тиковое ускорение: плотность тиков за `Tick Window` (3 с) ≥ `N` × средней плотности за `Baseline Bars` (100) баров;
   - AI Confidence ≥ `Min Confidence`;
   - сессия (только форекс), лимит позиций, дневной лимит убытка, пауза после серии убытков, кулдаун,
     запрет «догонять» цену дальше `Max Chase Beyond Trigger` × ATR от уровня пробоя.
3. **Объём.** `Fixed Lots Per Trade` (0 = риск `Risk Percent` от баланса на дистанцию SL с учётом комиссии),
   потолок `Max Lots` и максимум брокера, затем правила маржи (30 % свободной маржи на сделку, 90 % средств на все).
4. **Сопровождение.** SL = 0.8 × ATR(14) — серверный, ставится вместе с ордером (если брокер вернул позицию
   без стопа, бот ставит его сам, а если не получилось — сразу закрывает). TP1 = 1.0 × ATR закрывает 60 %;
   при +0.4R стоп переносится на вход + 0.1 пипса; остаток ведёт трейлинг 0.5 × ATR;
   если за 5 баров TP1 не достигнут — закрытие по рынку.

**«Пипс» на крипте.** Параметры в пипсах (буфер пробоя, глубина прокола, безубыток, шаг трейлинга,
проскальзывание) на форексе означают обычный пипс брокера. На крипте и других не-форекс символах один «пипс»
параметров = 0.5 базисного пункта цены: при BTC = 110 000 это $5.5. Так значения по умолчанию имеют один
смысл на всех рынках. Проскальзывание на крипте никогда не меньше текущего спреда.

## AI-модуль (Gaussian Naive Bayes)

- Своя модель на каждый символ. Вектор признаков `[Tick_Velocity, EMA20_Distance, RSI_Slope, Spread_Ratio]`:
  - **Tick_Velocity** — тики за последнее окно длиной в один бар / средний тиковый объём бара (логарифм);
  - **EMA20_Distance** — (цена − EMA20) / ATR со знаком направления сделки;
  - **RSI_Slope** — изменение RSI(14) за `RSI Slope Bars` баров со знаком направления;
  - **Spread_Ratio** — спред / ATR (линейно: на Razor спред часто ровно 0.0).
- **Метка.** «TP1 достигнут раньше SL/безубытка за `Label Horizon` баров» — прогон собственных правил выхода
  бота по будущим барам. Если SL и TP1 попали в один бар, считается проигрыш.
- **Обучение.** При старте — на истории (`Training Window` = 3000 баров: для форекса ~2 торговых дня M1,
  для крипты ~10 дней M5), дальше онлайн на каждом закрытом баре. Спред для разметки — медиана реальных
  спредов; после первых 300 тиков модель символа один раз перестраивается.
- **Confidence = P(win | x).** По умолчанию априорные вероятности равные, 50 % = «признаки нейтральны».
  Порог `Min Confidence` берётся только из UI.

```
MARKET BTCUSD: crypto | signal m5, ATR/time-exit m5 | spread/ATR <= 0.35 | 1 pip = 0.5 bp = 5.50 | volume min 0.01 step 0.01, lot 1 | ...

EURUSD SKIP [SQZ BUY @1.08540]: Low Tick Velocity (1.20x < 2.00x in 3.0s) | AI Confidence 28% < Target 50% [TV -0.21 EMA +0.05 RSI -0.40 SPR -0.12]
```

## Риски — прочитайте

- Настройки по умолчанию агрессивные, как и просили: 4 лота, 8 рынков, до 90 % средств в марже. Стоп на каждой
  позиции ограничивает убыток сделки, но не защищает от проскальзывания на новостях и резких движениях крипты.
- Скальпинг на M1 с комиссией ECN трудно сделать прибыльным; большинство розничных счетов на CFD теряют деньги.
  Никакой фильтр, в том числе AI, не гарантирует прибыль.
- Сначала — демо-счёт (как сейчас) минимум 1–2 недели и бэктест на тиковых данных. Для живого счёта уменьшите
  `Fixed Lots Per Trade` или поставьте 0 (тогда размер считается от `Risk Percent`).
- Безубыток +0.1 пипса не покрывает комиссию ECN: закрытие по BE на форексе — маленький минус.
