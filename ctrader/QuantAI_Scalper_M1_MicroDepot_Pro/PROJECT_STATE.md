## Архитектура (кратко)
- `Market` — всё состояние одного символа: бары сигнального и ATR-таймфрейма, индикаторы, тиковый движок,
  калибратор, трекер спреда, AI-модель, сетапы, счётчики STATUS, кулдаун и серия убытков.
- Тики: символ графика — через `OnTick`, остальные — через `Symbol.Tick`. На тике символа: тиковый движок →
  калибровка → спред → смена дня → закрытые бары (AI-разметка, сетапы) → дневной лимит → сопровождение
  позиций символа → проверка триггеров.
- `OnTimer` (1 с): сопровождение всех символов (выход по времени без тиков), STATUS, события сессии, HUD.
- Общие для счёта: дневной лимит убытка, лимит позиций, лимит сделок в день, правила маржи.
- Чистые классы без зависимостей от cTrader: `GaussianNaiveBayes`, `TickVelocityEngine`, `TickCalibrator`,
  `SpreadTracker`, `CommissionMath`, `OutcomeSimulator`, `VolmanSetups`, `SweepDetector`, `VolumeMath`,
  `AiFeatures`, `MarketMath` (списки символов, «пипс» не-форекс символов, правила маржи).

## Известные ограничения
- 4 лота × 8 рынков не помещаются в маржу 49 000 EUR при 1:30: первые сделки берут до 4 лотов, следующие меньше,
  после 90 % средств в марже новые входы отклоняются (`Total margin limit reached`).
- 50 EUR: одна позиция 0.01 лота на форексе; TP1 закрывает 100 % (0.01 лота не делится); BTC не по карману при 1:2.
- Безубыток +0.1 пипса не покрывает комиссию ECN (~0.6 пипса за круг, 4 лота ≈ $24).
- Исторического спреда в барах нет: разметка использует медиану реальных спредов (после 300 тиков символа —
  переобучение) или фиксированный `Training Spread Pips`.
- Фильтр спреда форекса 0.12 × ATR рассчитан на Raw/ECN-счёт; на стандартном счёте форекс-сделок почти не будет.
- Британские розничные счета (FCA): крипто-CFD могут быть недоступны — бот торгует только форекс.
- Новостного фильтра нет (в API cTrader нет экономического календаря).
- В облаке нет графиков: HUD и разметка видны только при запуске на ПК.
