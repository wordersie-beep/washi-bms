## Архитектура (кратко)
- `Market` — всё состояние одного символа: кандидаты таймфреймов и выбранный, бары, индикаторы, тиковый движок,
  калибратор, трекер спреда, AI-модель, сетапы, залог минимального объёма и наблюдаемый залог, расписание перерывов,
  счётчики STATUS, кулдаун и серия убытков.
- Старт символа: имя (варианты через `|` и по буквам) → цена и «пипс» → проверка бюджета (залог минимального объёма)
  → выбор таймфрейма по спреду → история, индикаторы, AI (`ConfigureTimeframe`). После 300 тиков спреда таймфрейм
  уточняется (переключение не больше одного раза, только без открытой позиции) и AI переобучается.
- Тики: символ графика — через `OnTick`, остальные — через `Symbol.Tick`. На тике: тиковый движок → калибровка →
  спред → смена дня → закрытые бары → дневной лимит → сопровождение → триггеры.
- `OnTimer` (1 с): сопровождение всех символов (выход по времени и перед перерывом без тиков), наблюдаемый залог,
  события рынков, STATUS, HUD.
- Бюджет: `BotEquity = min(средства счёта, Bot Budget + результат позиций, открытых после начала бюджета)`, залог бота —
  сумма `Position.Margin` этих позиций. Начало бюджета хранится в `LocalStorage` (Instance), результат читается из `History`.
- Чистые классы без зависимостей от cTrader: `GaussianNaiveBayes`, `TickVelocityEngine`, `TickCalibrator`,
  `SpreadTracker`, `CommissionMath`, `OutcomeSimulator`, `VolmanSetups`, `SweepDetector`, `VolumeMath`,
  `AiFeatures`, `MarketMath` (символы, таймфреймы, «пипс» не-форекса, ATR, перерывы, бюджет, правила маржи).

## Уроки прошлых версий, учтённые в коде
- Оценка залога брокером бывает занижена или NaN (5.6: 0.11 BTC заняло 40 % счёта) → максимум из трёх оценок.
- `NormalizeVolumeInUnits` не опускает объём ниже минимума → объём округляется своим кодом.
- `GetBars` для символа без графика отдаёт мало баров → явная догрузка `LoadMoreHistory` с ограничением запросов.
- Демо в облаке — один экземпляр → все рынки в одном боте.
- Переполненный журнал может остановить cBot → лимит строк SKIP, одна строка на трейлинг-позицию.
- Лимиты частоты приказов на демо → перенос стопа не чаще раза в 2 с и с шагом ≥ 0.05 ATR.
- Ключи LocalStorage допускают только латиницу, цифры и пробелы → ключ бюджета `QAI24x7 budget start`; сбой хранилища
  не останавливает бота (бюджет считается от старта).
- База тиков в барах своего таймфрейма растягивается на дни при h1 и не отражает текущую активность → база не длиннее
  2 часов, а калибровка счёта тиков — по M1 (3.2.0, по журналу Pepperstone).
- Сетап, взведённый до выходных или длинного перерыва, срабатывал на гэпе после открытия → такие сетапы сбрасываются.

## Известные ограничения
- На 20 EUR форекс недоступен (0.01 лота требует 28–38 EUR залога при 1:30); торгуется только недорогая крипта.
- BTC требует бюджета от ~400 EUR (0.01 BTC при 1:2).
- Безубыток +0.1 пипса не покрывает комиссию ECN.
- Исторического спреда в барах нет: разметка AI и выбор таймфрейма опираются на медиану реального спреда.
- Новостного фильтра нет (в API cTrader нет экономического календаря).
- В облаке нет графиков: HUD виден только при запуске на ПК.
