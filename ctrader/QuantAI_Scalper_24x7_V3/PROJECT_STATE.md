## Архитектура (кратко)
- `Market` — всё состояние одного символа: кандидаты таймфреймов и выбранный, бары, индикаторы, тиковый движок,
  калибратор, трекер спреда, AI-модель, сетапы, залог минимального объёма и наблюдаемый залог, расписание перерывов,
  счётчики STATUS, кулдаун и серия убытков.
- Старт символа: имя (варианты через `|` и по буквам) → цена и «пипс» → проверка бюджета (залог минимального объёма)
  → выбор таймфрейма по спреду → история, индикаторы, AI (`ConfigureTimeframe`). После 300 тиков спреда таймфрейм
  уточняется (переключение не больше одного раза, только без открытой позиции) и AI переобучается.
- Тики: символ графика — через `OnTick`, остальные — через `Symbol.Tick`. На тике: тиковый движок → калибровка →
  спред → смена дня → закрытые бары → дневной лимит → сопровождение → триггеры.
- `OnTimer` (1 с): сопровождение всех символов (выход по времени и перед перерывом без тиков), наблюдаемый залог,
  события рынков, STATUS, HUD.
- Бюджет: `BotEquity = min(средства счёта, Bot Budget + результат позиций, открытых после начала бюджета)`, залог бота —
  сумма `Position.Margin` этих позиций. Начало бюджета хранится в `LocalStorage` (Instance), результат читается из `History`.
- Тренд (3.5.0): на закрытии бара `EvaluateTrendChannel` взводит канал (максимум и минимум последних 20 баров);
  `EvaluateEntries` входит тиком за каналом (`TRD`), стоп 2 ATR без цели; `TrailTrend` на каждом новом баре ставит стоп
  за 10-барный канал (`MarketMath.ChannelStop`: только ближе к цене, при гэпе — закрытие). Позиция опознаётся после
  перезапуска по комментарию `QAI|TRD|…`. AI, тиковый фильтр, TP1, безубыток, выход по времени, пауза после серии
  убытков и минутные бары калибровки в этом режиме не используются.
- Чистые классы без зависимостей от cTrader: `GaussianNaiveBayes`, `TickVelocityEngine`, `TickCalibrator`,
  `SpreadTracker`, `CommissionMath`, `OutcomeSimulator`, `VolmanSetups`, `SweepDetector`, `VolumeMath`,
  `AiFeatures`, `MarketMath` (символы, таймфреймы, «пипс» не-форекса, ATR, перерывы, бюджет, правила маржи, канал
  и стоп тренда).

## Уроки прошлых версий, учтённые в коде
- Оценка залога брокером бывает занижена или NaN (5.6: 0.11 BTC заняло 40 % счёта) → максимум из трёх оценок.
- `NormalizeVolumeInUnits` не опускает объём ниже минимума → объём округляется своим кодом.
- `GetBars` для символа без графика отдаёт мало баров → явная догрузка `LoadMoreHistory` с ограничением запросов.
- Демо в облаке — один экземпляр → все рынки в одном боте.
- Переполненный журнал может остановить cBot → лимит строк SKIP, одна строка на трейлинг-позицию.
- Лимиты частоты приказов на демо → перенос стопа не чаще раза в 2 с и с шагом ≥ 0.05 ATR.
- Ключи LocalStorage допускают только латиницу, цифры и пробелы → ключ бюджета `QAI24x7 budget start`; сбой хранилища
  не останавливает бота (бюджет считается от старта).
- База тиков в барах своего таймфрейма растягивается на дни при h1 и не отражает текущую активность → база не длиннее
  2 часов, а калибровка счёта тиков — по M1 (3.2.0, по журналу Pepperstone).
- Сетап, взведённый до выходных или длинного перерыва, срабатывал на гэпе после открытия → такие сетапы сбрасываются.
- Данные символа о комиссии могут не совпадать с тем, что брокер реально берёт (демо Pepperstone: 0.1 пипса вместо ~0.6)
  → стоимость сделки = спред + комиссия, а комиссия уточняется по первой сделке (3.3.0).
- Безубыток +0.1 пипса на Razor терял комиссию (~0.5 пипса на выход) → стоп безубытка = вход + комиссия + 0.1 пипса.

## Известные ограничения
- Тренд на d1 торгует редко: 10–20 сделок в год на монету, позиция живёт 2–4 недели. Прибыльных сделок 40–60 %,
  убыточные обычно около −1R, прибыль делают несколько больших сделок. Первые сделки могут прийти через несколько дней.
- Крипта движется вместе: в обвал все покупки закрываются почти одновременно (до 8 позиций по ~1 % риска).
- Плата за перенос крипты (покупка ~20 % годовых) — около 1 % объёма позиции за 2–3 недели; в проверку включена.
- Стоп не защищает от гэпа: позиции держатся через перерывы, после гэпа выход по рынку (`CHANNEL EXIT`).
- Ниже — ограничения скальпера (`Strategy = Scalper`):
- На 20 EUR форекс недоступен (0.01 лота требует 25–47 EUR залога при плече счёта 1:25); торгуется только недорогая крипта.
- На 50 EUR — одна позиция форекса за раз (EURUSD 40 из 45 EUR лимита); GBPUSD нужен бюджет ~52 EUR.
- С комиссией Razor форекс торгуется на m15, а не на m1: на m1 спред с комиссией — около половины ATR.
- Альткоины Pepperstone (ADA, DOGE, UNI и др.) по официальному документу имеют средний спред 0.5–1 % цены — больше их
  обычного часового хода; в список по умолчанию не добавлены.
- На 50 EUR сделка — это центы; даже удачная неделя даёт единицы евро. Гарантии прибыли нет ни у одной стратегии.
- BTC требует бюджета от ~400 EUR (0.01 BTC при 1:2).
- Исторического спреда в барах нет: разметка AI и выбор таймфрейма опираются на медиану реального спреда.
- Новостного фильтра нет (в API cTrader нет экономического календаря).
- В облаке нет графиков: HUD виден только при запуске на ПК.

Бот сам пишет по каждой монете, с какого бюджета она начнёт торговаться.

## План роста (по просьбе «заработать много с 200 EUR»)
1. Демо с настройками по умолчанию (тренд) — смотреть `STATUS`, `ENTRY`/`PLAN`, `CHANNEL STOP`, `CLOSED`, `RESULTS`.
   Сделка на d1 длится в среднем 2–4 недели, сделок 1–2 в неделю на всех монетах вместе.
2. Реальный счёт — после первых 20–30 закрытых сделок на демо без технических сбоев и с результатом не хуже
   проверки. Вердикт `EARNING` после 100 сделок придёт нескоро (около года): у дневного тренда мало сделок.
3. Риск 1 % → 2 % (классика «черепах») удваивает и прибыль, и просадки. Поднимать только осознанно.
4. Честные ориентиры из проверки: в среднем +15–30 % в год при просадках до 10–20 % и отдельных убыточных годах.
   С 200 EUR это десятки евро в год; быстрый «очень большой» заработок без риска всё потерять невозможен.
