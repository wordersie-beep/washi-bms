# PHASE 2 — COUNTRY DISCOVERY

## Честное ограничение

По 20 странам запрошено больше 25 метрик, то есть больше 500 ячеек. Проверенными данными закрыта меньшая часть.

- Ячейки без источника помечены **UNKNOWN**.
- Ставки VAT/GST указаны по общеизвестным действующим значениям и помечены **K**: знание, перепроверить перед регистрацией.
- Метрики вроде CPC, AOV, chargeback по стране публично по странам не публикуются. Бесплатных надёжных источников нет, это UNKNOWN. Получить их можно только тестом.

«Лучшая страна» зависит от модели доставки. Модель доставки определяется тем, что с июля 2026 года изменилась экономика импортных посылок.

### Метрики без надёжного бесплатного источника (UNKNOWN по всем странам)

Покупательная способность в разрезе e-commerce, AOV по стране, CPC по стране, доля возвратов, chargeback rate, сроки доставки по перевозчикам.

- Для Meta есть только агрегированные бенчмарки: глобальный CPM ~$11.6–14.2 (S-27), CPM в США ~$16–20 (S-34).
- Отдельного бенчмарка по Ирландии не найдено.
- **Метод получения:** первые €20–50 теста в Meta Ads Manager (Reach estimate + фактический CPM) и Etsy Stats. Оценка ведётся по фактам, а не по блогам.

## Почему не Ирландия как единственный рынок

- **За Ирландию:** лучшая в ЕС склонность покупать онлайн (95.3%, S-26), нулевые таможенные трения для местного продавца.
- **Против:** маленький рынок (≈€8.8 млрд e-commerce по одной оценке и ≈$6.3 млрд по другой, S-28). Каждый покупатель — одновременно покупатель Temu/Shein (S-29) и Amazon.ie (S-22). Для товарной ниши это значит жёсткий ценовой якорь.

## Решение по странам

- **Основной рынок:** США.
  - Там 32 млн человек, связанных с Ирландией (S-50).
  - Товар печатается в США, поэтому пошлин и таможни нет.
  - Sales tax собирает Etsy (S-16).
- **Второй рынок:** Ирландия.
  - Сюда входят подарки родственникам за рубеж, заказанные из Ирландии, и продажи внутри Ирландии.
  - До €85k оборота регистрация НДС не нужна (S-02), но это требует подтверждения бухгалтера (см. `ireland-business.md`).
- **Следующие:** UK, Канада, Австралия.
  - Etsy собирает налог (S-15, S-17).
  - Открывать после подтверждения налоговой схемы.
- **Континентальный ЕС:** последним, только после письменного мнения налогового консультанта о VAT при POD-производстве в другой стране ЕС.
