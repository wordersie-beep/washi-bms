# Autopilot HQ — доход в интернете на автопилоте через Claude Code

Набор промптов, устав агента и файлы памяти, по которым Claude Code в облаке (Routines)
каждую ночь двигает твои интернет-проекты, а ты тратишь 2–3 часа в неделю с телефона.

**Честно:** полностью пассивного дохода с нуля не бывает. Здесь агент делает 80–90% работы:
код, данные, черновики, аналитику, мониторинг, починку. Ты — оставшиеся 10–20%: решения,
аккаунты, одобрение публикаций, общение с людьми. Реалистичная медиана через 12 месяцев —
€200–700 в месяц. Как посчитано — в `ANALYSIS.md`.

## С чего начать
1. **Прочитай** `ANALYSIS.md` (10 минут): что работает в 2026 году, 28 идей с оценками, топ-3.
2. **Сделай** 5 задач из `OWNER_INBOX.md` (≈ 1 ч суммарно).
3. **Дальше** агент работает по ночам. Раз в неделю приходит отчёт с задачами для тебя
   (≤ 5 × 30 мин).

## Карта файлов
| Файл | Зачем |

| `PLAN.md` | 90 дней по неделям, пороги «продолжаем / закрываем», недельный ритм |
| `CLAUDE.md` | устав агента: можно, только через владельца, никогда |
| `profile.md` | твой профиль — вход для анализа |
| `prompts/00-master-analysis.md` | **главный промпт анализа** — вручную или раз в месяц |
| `prompts/01-idea-validation.md` | проверка одной идеи за 14 дней |
| `routines/nightly-shift.md` | ночная смена: одна задача из бэклога за ночь |
| `routines/weekly-review.md` | воскресный отчёт: деньги, метрики, задачи тебе |
| `routines/monthly-strategy.md` | пересмотр стратегии на реальных цифрах |
| `routines/SETUP.md` | как включить: окружение, сеть, ключи, Routines, лимиты |
| `PROJECT_STATE.md` · `BACKLOG.md` · `OWNER_INBOX.md` · `METRICS.csv` · `DECISIONS.md` · `RUNLOG.md` · `CHANGELOG.md` | память автопилота между запусками |

## Как это работает
```
 каждую ночь   ─►  ночная смена: берёт верхнюю [auto]-задачу → код/данные → тесты → PR
 каждый день   ─►  ты: пуш-уведомления, одобрить PR (5–10 мин)
 воскресенье   ─►  недельный отчёт: € и метрики → бэклог → ≤ 5 задач тебе
 1-е число     ─►  стратегия: мастер-промпт на реальных цифрах → решения на твоё «да»
```

Этот репозиторий публичный: здесь нет личных данных, а рабочая копия HQ должна жить
в приватном `autopilot-hq` (`routines/SETUP.md`, шаг 0).
