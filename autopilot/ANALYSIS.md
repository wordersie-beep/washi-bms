# Анализ: доход на автопилоте через Claude Code в облаке

*Версия 1 · 25.09.2026 · сделан по методике `prompts/00-master-analysis.md` на профиле из `profile.md`*

## Итог в 5 строк

1. **Полностью пассивного дохода с нуля не бывает.** Реально получить схему, где агент делает
   80–90% работы, а ты тратишь 2–3 ч в неделю с телефона. Узкое место — не код, а покупатели.
2. **Мёртвые схемы 2026 года:** массовый AI-контент, шаблонные AI-видео, AI-книги, аффилиат-сайты
   без реального опыта. Площадки научились это находить и режут.
3. **Что работает:** софт и данные, которые продаются через площадку со встроенным спросом
   (App Store, Apify Store). Там покупателей приводит сама площадка, а Claude Code силён именно в коде.
4. **Основная ставка — фабрика Apify-акторов** на открытых данных, там больше всего автопилота.
   **Дополнительная — BridgeWard Pro**: твоё нечестное преимущество (реальная боль, которую ты
   знаешь изнутри, и готовый продукт). Прямой конкурент есть (HeadRoom), поэтому первым делом
   проверяем, насколько мы точнее по Ирландии. Обе ставки питает один ночной конвейер данных
   о габаритах.
5. **Реалистично через 12 месяцев:** медиана ≈ €200–700 в месяц, удачный сценарий €2–3 тыс.,
   плохой — около нуля. Решение «продолжаем или закрываем» — по порогам в `PLAN.md`, а не на вере.

## 2. Что агент в облаке может и чего не может

| Может сам (ночью, без тебя) | Только ты |
|---|---|
| Писать и чинить код: акторы, PWA, iOS, сайты | Регистрация, KYC, приём условий площадок, выплаты |
| Обновлять данные по расписанию с диффом и тестами | Любые траты и цены |
| Тесты, Playwright-скриншоты, деплой через GitHub и Netlify | Тест на реальном устройстве: GPS, BLE, в рейсе |
| Собирать метрики по API (ключи в окружении) | Посты в группах и сообществах, разговоры с людьми и компаниями |
| Исследовать рынок, конкурентов, отзывы | Нажать «опубликовать» для нового продукта (первый раз) |
| Черновики постов, писем, ответов на отзывы, описаний в сторах | Отправить письмо или ответ клиенту |
| Реагировать на события: продажа или PR через API- и GitHub-триггеры | Решение «продолжаем или закрываем» |

**Тонкие места.** В окружении по умолчанию стоит сеть *Trusted*: WebFetch к большинству сайтов
блокируется, WebSearch работает. Для исследований и API площадок нужно отдельное окружение
с расширенной сетью (`routines/SETUP.md`). Зелёный статус запуска значит только «сессия
отработала без сбоя», а не «задача сделана». Поэтому нужны `RUNLOG.md` и отчёты.

## 4. Топ-3: разбор

### Ставка 1 (основная) — фабрика Apify-акторов · балл 75

**Суть.** Портфель из 15–25 небольших акторов: сбор и обработка **открытых данных и
официальных API** без персональных данных. Каждый актор — маленький платный инструмент
с оплатой за событие. Apify сам приводит покупателей (поиск в Store), выставляет счета и
платит тебе 80%. Каждый актор автоматически доступен AI-агентам как MCP-инструмент.

**Почему ты.** Код пишет Claude, а ночная routine чинит акторы, когда меняются источники.
Флагман — твоя тема: **габаритные ограничения вдоль маршрута** (мосты и тоннели с `maxheight`
из OpenStreetMap). Он нужен разработчикам логистики, навигации для кемперов и AI-агентам,
а данные те же, что для BridgeWard.

**Кандидаты в портфель** (каждого проверяем спросом по `prompts/01` до сборки):
габариты вдоль маршрута (OSM) · госзакупки ЕС (официальный API TED) · солнечная генерация
по координатам для кемперов, яхт и домиков (API PVGIS Еврокомиссии) · зарядки для EV
(Open Charge Map) · обёртки над открытыми API Eurostat и ирландских ведомств для AI-агентов.

**Экономика** `[допущения: 15 акторов к 3-му месяцу, 25 к 6-му; у большинства 0–5 платящих]`

| | 3 мес | 6 мес | 12 мес |
|---|---|---|---|
| P10 | €0 | €10 | €20 |
| **P50** | €10–30 | €50–150 | **€150–400** |
| P90 | €100 | €500 | €1 500+ |

**Автопилот.** Ночью: здоровье акторов (доля упавших запусков) → починка → тесты → публикация
версии. Раз в неделю: метрики (пользователи, запуски, выручка) в `METRICS.csv`. Новые акторы —
по одному за ночь, только после проверки спроса.
**Твоё время:** 15 мин сейчас (аккаунт, API-токен в окружение) и 15 мин на реквизиты выплат
у первого актора, дальше ≈ 0.
**Риски:** низкая защищённость (конкуренты копируют) → берём количеством и нишами.
Условия сайтов и GDPR → только открытые данные и API. Лицензия OSM (ODbL) → атрибуция.
Лимиты публичного Overpass → держим свой снапшот данных.
**Тест за 14 дней:** опубликовать 3 актора → ≥ 10 уникальных пользователей суммарно. Нет —
меняем ниши (одна попытка), потом стоп.

### Ставка 2 (дополнительная) — BridgeWard Pro · балл 67

**Суть.** Нативное iOS-приложение, которое **в фоне** предупреждает о приближении к низкому
мосту на текущей дороге, **с любым навигатором** (Google Maps, Waze, штатный). PWA на iOS
в фоне работать не может, поэтому нужен натив. Для водителя подписка, для перевозчиков — флотская
лицензия.

**Доказательства спроса.** В Ирландии 80 ударов в железнодорожные мосты за 2024 год
(95 — за 2023-й). В Британии, по данным Network Rail, 1 666 за 2024/25 год: один удар каждые
пять часов и около £13 тыс. ущерба за каждый. Люди уже платят именно за такую функцию:
у HeadRoom (Low Clearance Map) есть режим Sentry с фоновыми предупреждениями о мостах —
$4,99 в месяц или $45 в год. Lorry Route — подписка £9,99, есть NaviTruck. **Спрос доказан,
но конкурент прямой.** Отличие BridgeWard — не идея «сторожа», а точность по Ирландии
(NI + RoI, проверено водителем в рейсах), цена, локальное сообщество и ирландские флоты.
Первое, что проверяем: насколько хорошо HeadRoom покрывает 123 известных тебе моста. Если
хорошо — ставка B слабеет, и это надо увидеть до написания Swift-кода.

**Нечестное преимущество.** Ты сам целевой пользователь, продукт уже работает (123 моста NI+RoI).
Можешь тестировать в реальных рейсах, и у тебя есть прямой доступ к водителям для первых отзывов.

**Экономика** `[допущения: €2,99/мес или €19,99/год, 500–2 000 установок за первый год, 3–5% платящих]`
P50 через 12 мес: **€50–250 в месяц** (B2C) + 1–3 флота по €2–3 за водителя (нужны твои
разговоры). P90 — €800+. Первые деньги — через 2–3 месяца (сборка, App Review).

**Автопилот.** Ночью: обновление базы мостов (OSM + опубликованный Irish Rail перечень
высот) с диффом → код → Xcode Cloud → TestFlight. Раз в неделю: ASO, мониторинг отзывов,
черновики ответов.
**Твоё время:** тест в рейсах (и так за рулём), 1 пост в неделю в группах водителей
(текст готовит агент), решение по ценам.
**Риски:** прямой конкурент с большой базой (HeadRoom) → выигрываем только точностью по
Ирландии и локальной дистрибуцией. Ответственность за безопасность → дисклеймер
«вспомогательная информация», точность данных важнее функций, геолокация только на устройстве. На iOS можно следить максимум
за 20 регионами одновременно → динамический пересчёт ближайших мостов. App Review.
**Тест — 14 дней после запуска лендинга (к концу недели 3):** лендинг + лист ожидания +
3 поста → ≥ 50 подписок **или** ≥ 10 водителей активно пользуются бесплатным PWA. Нет —
оставляем бесплатным PWA и не тратим время.

## 5. Юридика и налоги (Ирландия) — кратко, сверять с первоисточником

- **Побочный доход.** До €5 000 чистого в год — декларируется через myAccount как у PAYE-работника.
  Больше €5 000 чистого или больше €30 000 валового — регистрация в self-assessment,
  Form 11 через ROS (срок — 31 октября, при подаче онлайн — позже).
- **НДС.** Порог регистрации для услуг — €42 500 за скользящие 12 месяцев. При продажах через
  App Store и Merchant of Record НДС с покупателей платит площадка.
- **GDPR.** Не собираем персональные данные без нужды. В BridgeWard геолокация
  обрабатывается только на устройстве.
- **Лицензии.** Кадровое посредничество — лицензия WRC. Инвестсоветы и сигналы — регулируются.
  Обе темы не трогаем.
- **OpenStreetMap (ODbL):** атрибуция обязательна. Публично используемая производная база —
  share-alike.
- **Безопасность пользователей:** явные дисклеймеры в продуктах, которые влияют на решения за рулём.
