# Задачи владельцу — неделя 0

Не больше 5 задач, каждая ≤ 30 мин, всё с iPhone, кроме помеченного 💻.

### 1. Решение по ставкам — 5 мин
Напиши в чат одно из:
- «Да» — ставки A (Apify), B (BridgeWard Pro), M (MyGarage), приватный репо и Routines;
- «Да, но …» — что поменять.

### 2. Окружение «Autopilot» — 10 мин
claude.ai/code → меню окружения в заголовке сессии → новое окружение → по шагу 1 из
`routines/SETUP.md` (название, сеть `Custom` + список доменов оттуда).

### 3. Apify — 15 мин сейчас + 15 мин позже (после «да»)
1. apify.com → Sign up (Google-аккаунтом).
2. Console → Settings → API & Integrations → скопировать личный API-токен.
3. Настройки окружения «Autopilot» → API credentials → `APIFY_TOKEN` = токен.
   **Не в чат.**
4. Позже, когда агент подготовит первый актор к монетизации: Development → My Actors →
   актор → Publishing → Monetization → реквизиты и способ выплаты (PayPal от $20 или банк
   от $100). Вводишь только ты.

### 4. BridgeWard — 2 мин
Пришли в чат адрес сайта (например, `что-то.netlify.app`).

### 5. 💻 MyGarage → приватный репозиторий — 15 мин (когда будешь за MacBook)
1. Проверь, что в проекте нет API-ключей: они должны жить только на serverless-прокси.
2. Xcode → Integrate → New Git Repository (если репо ещё нет) → Integrate → Commit.
3. Source Control Navigator → Repositories → ПКМ на Remotes → **New "origin" Remote…** →
   GitHub → имя `mygarage` → **Private** → Create → Push.
4. Напиши в чат «mygarage залит».
